Landing Page for Graphic Design Site - Layers

Overview

A visually appealing landing page built with Next.js to showcase designers' latest work and mock-ups.

Features
- Accessibility First – Implemented semantic HTML5 and web accessibility features.
- Smooth Animations – Integrated Framer Motion for dynamic UI effects.
- Typed Components – Used TypeScript for type safety and maintainability.

Tech Stack
Next.js, TypeScript, Tailwind CSS, CVA, Framer Motion

Setup
1. Clone the repository
2. Install dependencies: npm install
3. Start the development server: npm run dev
